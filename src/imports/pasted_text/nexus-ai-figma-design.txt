QUALITY & PRODUCTION REQUIREMENTS
═══════════════════════════════════════════

• All components built with Figma Auto Layout (v4), constraints set for all screen widths
• All colors must use Figma Variables (not hardcoded), with light/dark mode modes
• All text must use Figma Text Styles
• All components must have documented property variants using Figma Component Properties
• Prototype: wire all navigation flows, hover states, modal opens, sidebar expand/collapse
• All interactive states: Default / Hover / Pressed / Focus / Disabled / Loading / Error
• Accessibility: minimum AA contrast on all text, focus rings on all interactive elements
• Export-ready: all icons as SVG components, all assets named with BEM convention
• Grid: 12-column, 24px gutters, 80px margins (desktop); 4-column (tablet); 2-column (mobile)
• All dashboards must include both Light Mode and Dark Mode frames side by side
